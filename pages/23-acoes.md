# 23. AÇÕES E PERÍMETROS

Ações criminosas, policiais ou de conflito devem possuir início, desenvolvimento e consequência.

{% hint style="info" %}
O objetivo de uma ação é produzir Roleplay. O resultado final é apenas uma parte da experiência.
{% endhint %}

## Preparação

Antes de iniciar uma ação, considere:

- Quantidade de participantes.
- Local.
- Presença de civis.
- Possibilidade de negociação.
- Regras específicas aplicáveis.
- Condições mínimas para desenvolvimento.

## Participantes

Respeite limites oficiais quando existirem.

É proibido adicionar participantes no meio da ação apenas para alterar artificialmente a vantagem.

## Terceiros

Jogadores externos à situação só devem interferir quando possuírem motivo plausível de RP.

## Perímetro

Uma ação em andamento pode gerar área de risco. Quem não participa deve evitar aproximação desnecessária.

## Reentrada

Jogadores removidos definitivamente da ação não devem retornar imediatamente para continuar o mesmo conflito.

## Finalização

Quando a cena terminar, respeite o resultado.

{% hint style="warning" %}
Não reinicie o mesmo confronto minutos depois apenas para tentar mudar o resultado anterior.
{% endhint %}
