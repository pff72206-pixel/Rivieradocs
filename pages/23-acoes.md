# 23. AÇÕES E PERÍMETROS

Ações criminosas ou policiais devem criar oportunidades de interação. O objetivo não é apenas ganhar, mas construir uma cena com começo, desenvolvimento e consequência.

- Respeite limites de participantes quando publicados.
- Evite iniciar ação sem tempo ou condições mínimas para desenvolvimento.
- Não leve conflitos para locais que prejudiquem jogadores completamente alheios sem necessidade.
- Interferência de terceiros exige motivo de RP.
