# 13. PACIFICAÇÕES

Pacificação é uma operação planejada para estabilizar uma área de risco, cumprir objetivos policiais relevantes ou restabelecer o controle de uma região.

## Planejamento

Toda operação deve possuir:

- Comando definido.
- Objetivo claro.
- Comunicação entre equipes.
- Divisão de funções.
- Critério de início e encerramento.

## Perímetro

Sempre que possível, a área deve ser delimitada e civis devem receber oportunidade razoável para se afastar.

Entradas e saídas podem ser controladas quando houver justificativa operacional.

## Uso da força

A presença de uma operação de pacificação não autoriza força indiscriminada.

O uso de armamento deve respeitar:

- Nível de ameaça.
- Presença de civis.
- Condições do local.
- Ordem do comando.

## Civis e terceiros

Jogadores sem relação com o conflito não devem interferir deliberadamente na operação apenas para provocar a polícia.

{% hint style="warning" %}
Entrar repetidamente em uma área claramente isolada pode ser interpretado como interferência indevida.
{% endhint %}

## Encerramento

A pacificação termina quando:

- O objetivo for cumprido.
- A área estiver estabilizada.
- O comando determinar retirada.
- A operação perder justificativa ou segurança.
